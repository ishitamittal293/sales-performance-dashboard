# Sales Performance Dashboard | Power BI

## Overview
An end-to-end sales analytics dashboard built on a public retail 
dataset to analyze regional performance, category trends, and 
customer insights.

## Key Metrics Tracked
- Total Sales: $2.33M
- Total Profit: $292K
- Total Orders: 10K
- Profit Margin: 12.56%

## Key Insights
- West region leads in both sales and profit
- Technology is the highest revenue-generating category
- Central region shows lower profitability — identified as 
  an improvement opportunity
  
## Analytical Approach
Filtered and aggregated sales data across dimensions including 
Region, Category, and Month to surface profitability patterns 
and identify underperforming segments for business recommendations.

## Tools Used
- Power BI Desktop
- Dataset: Public retail sales dataset (Superstore)
